# WoW Helper

Telegram-бот для **World of Warcraft: Forever**, который будет отслеживать изменения игры и отправлять персонализированные уведомления с учётом персонажа пользователя.

> Проект находится на ранней стадии. Сейчас формируется базовая техническая основа, пользовательские функции ещё не готовы.

## Планируемый стек

- Bun
- TypeScript
- Elysia
- grammY
- PostgreSQL
- Kysely
- OpenAI и/или Anthropic
- Docker

## Локальный запуск

Установить зависимости:

```bash
bun install
```

Запустить API:

```bash
bun run dev:api
```

Запустить проверки:

```bash
bun run typecheck
bun test
```
